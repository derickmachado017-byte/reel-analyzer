# ReelAnalyzer

Ferramenta web experimental para abrir links públicos do Instagram pelo player oficial e extrair quadros de vídeos enviados pelo usuário.

## Recursos
- Interface responsiva em português.
- Tentativa de abrir Reels pelo embed oficial do Instagram.
- Seleção local de vídeo e extração de quadros no navegador.
- Exportação de painel JPG com os quadros extraídos.

## Executar
Abra `index.html` em um navegador moderno. Não precisa de instalação, chave de API ou servidor.

## Publicar na Vercel
Importe este repositório na Vercel. A pasta raiz contém o `index.html`; não há comando de build.

## Limitações
O Instagram pode impedir embeds, exigir login ou alterar suas regras. O projeto não contorna autenticação, privacidade, limites ou bloqueios. Se o embed não funcionar, use um vídeo que você tenha autorização para acessar e envie-o pela seção de upload.

A extração é local no navegador. Para analisar com o ChatGPT, baixe o painel e anexe-o à conversa.

Não coloque senhas, cookies ou tokens do Instagram neste projeto.
